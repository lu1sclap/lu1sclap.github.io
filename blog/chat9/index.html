生活日常 talk

Mar 7, 2026 - 1 minute read

大家午安，這裡是路易斯掌聲，我是 Louis，現在時間是 2026/03/07 的中午的 12 點整，簡單泡了杯拿鐵，就開始來寫文章啦。

原本想說出門吃個生魚片再回來寫的，但我女友還在睡覺，我也不曉得她要睡到幾點？想說剛好可以趁這個時候來寫，且說不定寫完她就起床了。

上次和女友討論說要一起寫個 2026 的年度計劃，她倒是蠻早就開始計劃了，帶她家人去日本玩、養成存錢習慣、養成運動習慣、一起做十件有趣的事、但最重要的一點她有說那就是不要對我那麼兇（哈。

而我內心 26 年其中一件規劃，那就是「計劃跳槽」，只不過這次的跳槽跟以往都不太一樣，雖然我也沒有很常換工作，但上次換工作是被忽悠忽悠的就簽自願離職單了，好虧喔！我的資遣費，且我以往的做工作也都是相同類型的產業。

而這次我在工作的選擇上會比較嚴謹，目前規劃也是會選擇同產業，但會挑一些工作內容相對於我現階段來說是比較有難度的工作，也會開始針對自己的不足去做補強，薪資當然也是要大幅度的提高才有意義，補強計劃目前也已經跑了兩週左右，我只能說學習 Design Pattern 是真的不容易（揮汗。

人生是需要 Refactoring 的，但先別急著想斷捨離

重構（Refactoring）一詞，白話就是重新建構，它源自於程式碼之中，在不改變軟體外部的行為的前提下，優化其內部結構的過程，比如說你想去 D 點，走 A -> B -> C -> D 會到，但你發現了現在可以 A -> E -> D 就到，這不是一件很值得高興的事情嗎？因為誕生了一個新的解決辦法，但不知道有沒有人會跟我一樣會很在乎過去的 B -> C 這兩點，也會下意識的想讓 B、C 與自己脫離關係，就像是很怕如果過去的自己被人發現了會被當成一個把柄一樣，就跟一些無腦偶像劇演的劇情一樣，女主角總是想隱瞞自己過去，只為了不讓豪門公婆對自己有成見，我現在覺得真的超鳥，之前怎麼都沒發現呢？真是弔詭。

後來我才發現，這種想跟 B、C 點斷捨離的急迫感，其實源自於一種深層的不安全感，我們之所以想隱瞞過去自認為不好的那一面，是因為我們潛意識裡覺得現在的自己還不夠好不夠完美，也太在意他人的眼光了，那些看似很不好的 B -> C -> D 路徑，其實都是為了讓現在的 E -> D 跑的更穩，也是成長的必經過程，不然怎麼會叫成長，成長就是從不好 -> 好的過程。

我不適合太急迫性的做計劃

為什麼要做計劃？我覺得做計劃是為了讓自己有明確的方向感，知道自己現在該往哪裡前進，而計劃也有分遠到近，以及是否需要改變當下生活的節奏？較遠的計劃可以透過將計劃具體數字化出來，就可以逐漸的擬定出較近的計劃了。

但你如果是那種超級急迫性的做計劃的人，且如果這個計劃會需要你改變當下的生活節奏，那我認為你計劃的執行力一定不高，你現在在熬夜追劇，但你卻計劃著想明天早起去 6:00 去健身，雖然還是有人可以做到，但我發現我比較沒辦法，而我還發現了一件很酷的事情，那就是原來計劃的執行力高低會連帶的影響你的自信心。

原因是來自於你的大腦，如果你的執行力越高，它越會帶給你一種正能量的加成，你會有一種對於生活上的掌控感，無形中你的能力也都在提升，你可以勝任更困難的任務，並且贏得他人信賴，同時也會對生活感到樂觀，聽起來很棒吧！這就是建立自信心的來源。

反之，當你對自己許下承諾卻沒做到時，大腦會接收到一個訊號，那就是我說的話是不算數的，而且也沒什麼能量，久而久之，自我價值感就會崩塌，這其實是件很可怕的事情，畢竟沒人會想讓自己是個沒自信的人吧？
